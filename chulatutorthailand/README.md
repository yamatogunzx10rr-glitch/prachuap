# Best Tutor Thailand - Language School Website

เว็บไซต์โรงเรียนสอนภาษาจีน + ระบบหลังบ้าน พร้อมเมนูครบทุกวิชาตาม Best Tutor Thailand

## Demo
ไฟล์ index.html นี้พร้อมรันเลย

## Features
- หน้า Landing ภาษาจีน + รูปจริง 100%
- Mega Menu ครบ: ภาษา (อังกฤษ จีน ญี่ปุ่น เกาหลี) / วิทย์ คณิต / ดนตรี กีต้าร์ เปียโน / กีฬา ว่ายน้ำ เทควันโด แบดมินตัน โยคะ
- Section วิชาอื่นๆ ที่เปิดสอนทั้งหมด
- หลังบ้าน Admin: จัดการลีด คอร์ส รีวิว วิชา
- Responsive + Kanit Font

## Deploy to GitHub Pages
1. สร้าง repo ใหม่บน GitHub ชื่อเช่น `best-tutor-thailand`
2. Upload ไฟล์ทั้งหมดในโฟลเดอร์นี้
3. ไปที่ Settings > Pages > Branch: main / root > Save
4. รอ 1-2 นาที จะได้ลิงก์ https://username.github.io/best-tutor-thailand/
